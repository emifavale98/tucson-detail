# Tucson Detail

Tucson Detail es un taller de detailing. Como mis hobbies y pasiones son los autos, decidí encarar el proyecto por ese lado, combinando dos cosas que me gustan: los autos y la programación, en la cual estoy aprendiendo.

## Páginas

El sitio tiene 5 páginas: Inicio, Servicios, Precios, Galería y Contacto.

## Tecnologías

Se utilizó HTML5 y CSS.
